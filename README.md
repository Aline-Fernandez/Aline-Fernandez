# ✨ Sobre mim

Sou graduada em **Análise e Desenvolvimento de Sistemas (2024)** e, atualmente, curso **Bacharelado em Engenharia de Software** e **Pós-graduação em Engenharia de Software com Métodos Ágeis**. Meu foco é construir uma carreira sólida baseada em boas práticas de desenvolvimento, qualidade de código e agilidade.

Atualmente, dedico meus estudos ao ecossistema **Java**, explorando o desenvolvimento backend e automação de testes. Minha trajetória anterior me trouxe uma **maturidade diferenciada** na resolução de problemas complexos, atenção minuciosa a detalhes técnicos e uma visão analítica voltada para a melhoria de processos.

Como **DIO Campus Expert**, busco constantemente contribuir com a comunidade e aplicar conceitos de **Scrum, Kanban e testes unitários (JUnit)** para entregar software de alto valor.
